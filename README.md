# Simple Interest Calculator

A simple, interactive web-based application designed to calculate simple interest based on the principal amount, interest rate, and time duration in years.

## Description
This project was developed as part of the IBM Full Stack Software Developer Professional Certificate. It allows users to input their principal amount, select an annual interest rate via an interactive slider, choose the duration in years, and receive an instant breakdown of the accrued interest along with the projected maturity year.

## Features
- **Dynamic Slider Input:** Interactive interest rate slider displaying real-time percentage updates.
- **Input Validation:** Prevents submission of zero or negative numbers with descriptive user alerts.
- **Accurate Time Projection:** Automatically calculates the exact future calendar year when the investment matures.
- **Clean Responsive UI:** Minimalist and accessible CSS styling.

## Technologies Used
- HTML5
- CSS3
- JavaScript
